# Cross-Repo Learning

## Purpose

Capture reusable patterns and learnings to update the template repo.

## When to Use

- Discovered a gotcha worth documenting
- Found a pattern that applies to multiple projects
- Solved a problem that will recur
- End of significant feature work

## Learning Categories

### Project Context Updates

Patterns that should be in every project's context file:
- Safety rules (git, database, deployments)
- Tool preferences
- Project structure conventions

### Knowledge Docs

Reusable technical guides for `docs/knowledge/`:
- Service integrations (Supabase, GCP, etc.)
- Framework patterns
- Infrastructure setup guides

### User Preferences

Cross-project preferences:
- Code style
- Communication preferences
- Account and auth conventions

## Sync Process

1. Identify the learning and category
2. Determine target (template repo or user preferences)
3. Draft the addition
4. Apply to the template repo
5. Consider backporting to active projects
